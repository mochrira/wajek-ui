# Wajek UI

## Problem

Wajek Studio membutuhkan Framework UI yang konsisten di setiap aplikasi web yang dikembangkan.

## Tujuan

Membuat user interface yang :
- Sesuai dengan konsep material design dari google (m3.material.io)
- Menggunakan Angular Material CDK (material.angular.dev/cdk) sebagai basis komponen
- Menyediakan tema gelap (dark) dan tema terang (light)
- Terdokumentasi dengan baik terkait dengan bagaimana cara memulai, menggunakan dan kustomisasi tema
- Output project berupa library yang bisa di publish ke npmjs.com dengan project utama berupa dokumentasi dan demo penggunaan setiap komponen
- Menggunakan se-native mungkin tag html yang sudah ada
- Maksimalkan penggunaan directive sebelum memutuskan menggunakan component.
- Bisa juga digunakan di standalone component.

## Fitur Dasar

- Layout
- Sidenav
