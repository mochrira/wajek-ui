# WuiPage

> Halaman pertama 

## Deskripsi

Ini adalah halaman pertama saat membuat component page untuk memulai pembuatan

## Fitur Utama

- **Fitur 1**: Ada Light Mode dan Dark Mode


### Cara Menggunakan

1. Buka halaman component htmlnya dan ketik: **Wuipage**.
2. isi dari Wui Page : **WuiPage > WuiAppBar**
